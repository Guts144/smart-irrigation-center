2. Problem Statement

  • Global Water Crisis: Agriculture consumes 70% of freshwater.
  • Inefficient traditional irrigation leads to massive water waste.
  • Lack of real-time monitoring for soil and climate variance.
  • Emergency Situations: No automated response to fire or extreme drought.

3. System Architecture

Holistic Integration

  • Edge Node: ESP32 + DHT22 + Soil Sensors (Wokwi Simulation).
  • Transmission: Lightweight MQTT Protocol via HiveMQ.
  • Persistence: SQLite Database for historical auditing.
  • Client: JavaFX Desktop Dashboard with Role-Based Access.

4. Hardware Implementation

The IoT Edge Node

  • ESP32 Microcontroller: Low-power, integrated Wi-Fi.
  • Sensors: Humidity/Temperature (DHT22) & Analog Soil Moisture.
  • Control: GPIO-driven Relay for Irrigation Valve (Simulated via LED).
  • Auto-Reconnect Logic: Ensures data continuity in case of network drops.

5. Data Flow & Communication

  • Upstream: Sensors → ESP32 → JSON Serialization → MQTT Publish.
  • Downstream: MQTT Subscribe → Desktop Client → GSON Parsing → SQLite Persist.
  • Control: Dashboard Command → MQTT Publish → ESP32 Subscribe → GPIO Toggle.

6. Security & Role-Based Access

  • Authentication: Encrypted local credential validation.
  • Admin Role: Access to MQTT Cloud settings, Broker configuration, and Bulk Exports.
  • Operator Role: View real-time telemetry and manual valve control.
  • UI Logic: Dynamic navigation hiding for unauthorized users.

7. Software Design: JavaFX & FXML

  • View: XML-based FXML for declarative UI structure.
  • Controller: Java logic handling UI events and MQTT background tasks.
  • Service Layer: Singleton MqttService for application-wide connectivity.
  • DAO Layer: Dedicated Data Access Objects for SQL interactions.

8. Automated Safety Systems

  • Visuals: Lush gradients and Glassmorphism effects.
  • Responsive: Real-time gauges and vertically stacked line charts.
  • Analytics: Detailed historical view with CSV Export support.
  • Security: Admin vs. Operator roles for system integrity.

8. Conclusion & Results

  • Successfully automated irrigation based on environmental triggers.
  • Optimized database performance with efficient indexing.
  • Created a professional, high-fidelity UI for user engagement.
  • Future Scope: AI/ML predictive models for climate forecasting.
